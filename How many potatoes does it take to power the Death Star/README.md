# How many potatoes does it take to power the Death Star?

As part of my answer to this question, I came up with a fun formula which gave rise to the following general purpose calculators:
1) Calculates the number of potatoes you'd need to output a certain amount of power for a certain number of hours.
2) Calculates how long a given number of potatoes could output a certain wattage.

Have fun and play with the thing [here](https://l-amos.github.io/dumbsciencethings.github.io/How%20many%20potatoes%20does%20it%20take%20to%20power%20the%20Death%20Star/index.html)!
