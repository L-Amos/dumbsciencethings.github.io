# How many fireworks would it take to launch someone into space?

As part of my answer to this question, I came up with some useful formulae. These allowed me to create two general purpose calculators:
1) Calculates the number of fireworks required to launch a pilot of a given weight up to a desired height.
2) Calculates the height and velocity a pilot of a given weight would reach if launched with a desired number of fireworks.

Both calculators have optional sliders to vary the weight of the mortar used to fire the firework shells. In the case of the first calculator, the minimum mortar weight to reach your desired height is also given.

Have fun and play with the thing [here](https://l-amos.github.io/dumbsciencethings.github.io/How%20many%20fireworks%20would%20it%20take%20to%20launch%20someone%20into%20space%3F/index.html)!
